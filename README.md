# Halloween Free Book Drive

A responsive Halloween-themed free book drive application.

## Application Overview

The Halloween Free Book Drive allows users to browse a collection of books and freely take a book during the Halloween season.

Users may optionally leave a note about the book they selected.

## Main Features

- Browse available books
- View book information
- Take a free book
- Optionally leave a note
- View books already taken
- Local storage for saved book selections
- Responsive layout for different screen sizes
- Halloween-themed user interface

## Technologies

- HTML
- CSS
- JavaScript
- Local Storage
- Ionic/Cordova Android build environment

## Project Files

- `index.html` — Main application interface
- `style.css` — Responsive styling
- `app.js` — Application functionality and local storage
- `config.xml` — Cordova configuration
- `README.md` — Project documentation

## Local Storage

The application uses browser local storage to save books taken by the user.

The stored information includes:

- Book ID
- Book title
- Author
- Optional note
- Date taken

## Responsive Design

CSS media queries are used to adjust the layout for smaller screens.

The application can therefore be viewed on desktop and mobile-sized screens.
